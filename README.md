# 🐍 Python from Scratch — Module 1: First Steps

An interactive Jupyter Notebook designed for a solid refresher and structuring of Python fundamentals. Built with a clean layout and locked theory cells to keep the focus entirely on coding practice.

## 📌 What's Inside

* **Core Theory & Examples:** Clear explanations covering variables, basic data types (`int`, `float`, `str`, `bool`), comments, arithmetic/comparison/logical operators, type conversion, `input()`, and f-strings.
* **Interactive Exercises:** 7 hands-on tasks ranging from basic printing to a BMI calculator, complete with expandable spoiler solutions.
* **Protected Content:** Theory and description cells are configured as non-editable (`"editable": false`, `"deletable": false`) to prevent accidental changes while working through the material.
